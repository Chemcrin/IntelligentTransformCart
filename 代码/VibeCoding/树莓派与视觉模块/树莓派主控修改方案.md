| 输入  | 发送给 STM32          | 小车动作      |
| --- | ------------------ | --------- |
| `o` | 不发送或发送 `$STOP\r\n` | 进入手操模式    |
| `w` | `$FWD\r\n`         | 前进        |
| `s` | `$BACK\r\n`        | 后退        |
| `a` | `$LEFT\r\n`        | 左平移30mm   |
| `d` | `$RIGHT\r\n`       | 右平移30mm   |
| `x` | `$STOP\r\n`        | 停止        |
| `e` | `$CW,5\r\n`        | 顺时针转 5 度  |
| `r` | `$CCW,5\r\n`       | 逆时针转 5 度  |
| `l` | `$LASER\r\n`       | 查询激光距离    |
| `y` | `$YAW\r\n`         | 查询偏航角     |
| `p` | `$STOP\r\n`        | 退出手操模式并停止 |
| `q` | `$STOP\r\n` 后退出    | 退出程序      |

核心修改逻辑可以这样设计：

```
manual_mode = False

if key == 'q':
    ser.write(b"$STOP\r\n")
    break

if key == 'o':
    manual_mode = True
    ser.write(b"$STOP\r\n")
    print("进入小车手操模式")
    continue

if manual_mode:
    if key == 'w':
        ser.write(b"$FWD\r\n")
    elif key == 's':
        ser.write(b"$BACK\r\n")
    elif key == 'a':
        ser.write(b"$LEFT\r\n")
    elif key == 'd':
        ser.write(b"$RIGHT\r\n")
    elif key == 'x':
        ser.write(b"$STOP\r\n")
    elif key == 'e':
        ser.write(b"$CW,90\r\n")
    elif key == 'r':
        ser.write(b"$CCW,90\r\n")
    elif key == 'p':
        ser.write(b"$STOP\r\n")
        manual_mode = False
    ser.flush()
    continue
```

有一个关键决策需要注意：你现在这个 `usb_debug(4).py` 原本是“机械臂动作组控制”，波特率是 `9600`，发送的是 `55 55 ...` 二进制帧；而小车底盘协议是 `115200`，发送的是 `$FWD\r\n` 这种 ASCII 字符串。如果这两个功能走的是同一个 CH340N 串口、同一个 STM32 UART2，那么 STM32 端也必须同时支持这两套协议，或者你需要把这个脚本改成“小车底盘专用调试脚本”。

我的建议是下一步直接改成一个兼容版本：保留 `0-200` 动作组控制，同时把默认波特率改为 `115200`，加入 `o` 手操模式和 WASD 映射。这样最贴合你现在“树莓派 USB 串口 -> CH340N -> STM32 UART2”的通信情况。
