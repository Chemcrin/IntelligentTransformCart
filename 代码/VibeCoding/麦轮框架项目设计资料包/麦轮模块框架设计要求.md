## 已确认机械与坐标约束

### 1. 四轮位置与电机地址

四个电机地址与小车位置关系固定如下：

```text
车头方向：+Y

左前轮  右前轮
0x01    0x02

左后轮  右后轮
0x03    0x04
```

| 轮子位置 | 电机地址 | 说明 |
|---|---:|---|
| 左前轮 | `0x01` | 固定映射，不允许后续模型擅自修改 |
| 右前轮 | `0x02` | 固定映射，不允许后续模型擅自修改 |
| 左后轮 | `0x03` | 固定映射，不允许后续模型擅自修改 |
| 右后轮 | `0x04` | 固定映射，不允许后续模型擅自修改 |

---

### 2. 麦轮安装纹路

麦克纳姆轮安装纹路已确认：

| 项目 | 约束 |
|---|---|
| 安装形态 | X 型交叉状 |
| 纹路关系 | 斜对角线方向上的麦轮纹路方向相同 |
| 后续要求 | 运动学符号必须基于该安装方式设计，并在测试流程中加入方向验证 |

若实际运动方向与理论方向不一致，后续代码生成时只能通过方向修正系数或电机方向配置调整，不得改变电机地址映射。

---

### 3. 车体坐标系定义

根据陀螺仪安装位置，车体坐标系固定如下：

| 坐标轴 | 正方向 | 含义 |
|---|---|---|
| X 轴 | 小车左侧 | 横移方向 |
| Y 轴 | 小车正前方 | 前后运动方向 |
| Z 轴 | 小车正上方 | 旋转轴方向 |

运动控制接口应优先使用该坐标系定义。

建议速度向量命名保持一致：

| 参数         | 含义                     | 单位    |
| ---------- | ---------------------- | ----- |
| `vx_mps`   | X 轴方向速度，向左为正           | `m/s` |
| `vy_mps`   | Y 轴方向速度，向前为正           | `m/s` |
| `wz_radps` | 绕 Z 轴角速度，正方向待结合陀螺仪定义确认 | `RPM` |

## 接口设计硬性要求

### 1. 上层底盘控制接口

必须规划面向控制层调用的高级接口，例如：

| 接口类型 | 示例函数名 | 说明 |
|---|---|---|
| 初始化 | `Mecanum_Init()` | 初始化麦轮模块 |
| 停止 | `Mecanum_Stop()` | 停止四个电机 |
| 急停 | `Mecanum_EmergencyStop()` | 立即停止并进入保护状态 |
| 速度向量控制 | `Mecanum_SetVelocity(vx_mps, vy_mps, wz_radps)` | 按车体坐标系控制底盘运动 |
| 前进后退 | `Mecanum_MoveForward(speed_mps)` / `Mecanum_MoveBackward(speed_mps)` | Y 轴运动 |
| 左右横移 | `Mecanum_MoveLeft(speed_mps)` / `Mecanum_MoveRight(speed_mps)` | X 轴运动 |
| 原地旋转 | `Mecanum_Rotate(wz_radps)` | 绕 Z 轴旋转 |
| 状态查询 | `Mecanum_GetState()` | 获取模块状态 |

函数名若与 `工程变量总览.md` 冲突，必须按该文档调整。

---

### 2. 底层 ZDTX42 电机接口

必须规划面向 ZDTX42 的单电机底层接口，至少包括：

| 接口类型 | 示例函数名 | 说明 |
|---|---|---|
| 单电机速度设置 | `ZDTX42_SetMotorSpeed(motor_id, speed_mps)` | 给指定电机设置目标速度 |
| 单电机停止 | `ZDTX42_StopMotor(motor_id)` | 停止指定电机 |
| 全部停止 | `ZDTX42_StopAllMotors()` | 停止所有电机 |
| 电机使能 | `ZDTX42_EnableMotor(motor_id, enable)` | 控制指定电机使能状态 |
| 通信发送 | `ZDTX42_SendFrame(motor_id, frame, length)` | 通过 RS485/UART3 发送命令帧 |
| 通信接收 | `ZDTX42_ReceiveFrame(buffer, length, timeout_ms)` | 接收 ZDTX42 响应 |
| 通信校验 | `ZDTX42_CheckFrame(frame, length)` | 校验响应帧，具体校验方式待资料确认 |
| 错误处理 | `ZDTX42_HandleError(error_code)` | 处理通信或电机异常 |

如果协议命令字、帧格式、校验方式、速度换算关系未在资料中明确，必须标注 `待确认`，不得补写具体字节。

## 麦轮运动学约束

文档必须基于以下变量组织运动学关系：

| 变量 | 含义 | 单位 | 正方向 |
|---|---|---|---|
| `vx_mps` | 横向速度 | `m/s` | 向小车左侧为正 |

| `wz_radps` | 绕 Z 轴角速度 | `rad/s` | 正方向待结合陀螺仪与实车验证，若资料未说明则标注 `待确认` |

| 变量 | 含义 |
|---|---|

| `wheel_fr_mps` | 右前轮目标线速度 |
| `wheel_rl_mps` | 左后轮目标线速度 |
| `wheel_rr_mps` | 右后轮目标线速度 |

运动学公式可以给出“符号关系与待验证说明”，但若轮径、轮距、轴距、减速比、ZDTX42内部速度单位未确认，不得给出最终硬编码换算。
