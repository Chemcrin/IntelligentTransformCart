## 9. 仍建议后续统一的变量名

硬件手册 V3 推荐使用 `g_imu_car_*`、`g_imu_acc_*`、`g_imu_gyro_*`、`g_laser_*` 体系。本次按照任务书要求没有改动现有变量名。后续更新硬件手册或重构接口时，可按如下方向统一：

| 当前变量 | 建议长期变量 |
|---|---|
| `car_yaw_est_deg` | `g_imu_car_yaw_est_deg` |
| `car_pitch_deg` | `g_imu_car_pitch_deg` |
| `car_roll_deg` | `g_imu_car_roll_deg` |
| `gyro_yaw_dps` | `g_imu_gyro_yaw_dps` |
| `acc_forward_g` | `g_imu_acc_forward_g` |
| `acc_right_g` | `g_imu_acc_right_g` |
| `acc_down_g` | `g_imu_acc_down_g` |
| `temperature_c` | `g_imu_temperature_c` |
| `laser_ok` | `g_laser_ok` |
| `laser_warning` | `g_laser_is_warning` 或保留等级变量 `g_laser_warning_level` |
| `laser_slow` | `g_laser_is_slow` |
| `laser_too_close` | `g_laser_is_too_close` |
