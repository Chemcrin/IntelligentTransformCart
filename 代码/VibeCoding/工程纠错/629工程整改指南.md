## 项目背景
基于STM32的智能物流小车，其底盘电机通过RS485总线控制。由于硬件设计限制，RS485接口当前仅具备单向发送能力，无法接收来自电机驱动器的状态回传信号。
#  核心需求
## 1. 电机只发不收开环控制确认
在保证小车能正常完成前进、后退、转向等基本运动功能的前提下，确认电机控制策略调整为**只发不收的开环控制**。软件架构必须彻底移除对电机反馈数据的依赖，仅保留控制指令下发通路。
故可以移除一些用于接收电机运行状态回传的函数比如空实现的`MotorManager_UpdateFeedback()` 

## 2. 陀螺仪辅助纠偏功能完善

### **总体思路**

| 项目    | 方案 B 设计                                    |
| ----- | ------------------------------------------ |
| 保留内容  | 固定路线、ZDT 电机下发、原来的时间开环距离控制全部保留              |
| 新增内容  | 只启用 IMU yaw 数据；只在直线前进/后退时做轻量纠偏             |
| 控制方式  | 进入直线段时记录当前 yaw 为目标航向，行驶中持续比较当前 yaw 和目标 yaw |
| 修正方式  | yaw 偏左/偏右时叠加很小的 `wz`，让四轮 RPM 自动产生差速修正      |
| 回退策略  | IMU 无效、未校准、数据超时、偏差异常时，立即退回原来的开环直行          |
| 不启用内容 | 不启用激光、不启用树莓派、不启用完整 `Board_App`，避免旧逻辑干扰     |

推荐的数据流是：

```
固定路线目标速度 vy
        ↓
读取 IMU yaw
        ↓
计算 yaw_error = target_yaw - current_yaw
        ↓
PID/比例控制得到 correction_wz
        ↓
修正速度: vx 不变, vy 不变, wz += correction_wz
        ↓
麦轮逆运动学
        ↓
四个 ZDT 电机 RPM
```

**直线纠偏触发条件**

| 条件         | 建议规则                           |
| ---------- | ------------------------------ |
| 只在直线段启用    | `abs(vy) > 0.03 m/s`           |
| 不在横移时启用    | `abs(vx) < 0.01 m/s`           |
| 不在主动旋转时启用  | `abs(wz) < 0.01 rad/s`         |
| IMU 必须有效   | `imu_valid == 1`               |
| IMU 必须完成校准 | `imu_calibrated == 1`          |
| yaw 数据不能超时 | 当前 tick 与 IMU 最后更新时间差不超过阈值     |
| 偏差异常时退出    | 例如 yaw 偏差超过 `20~30 deg`，不要强行纠偏 |

**关键点：不要边走边做陀螺仪零偏校准，启动前校准传感器，行驶中保持航向。**

| 概念            | 建议                          |
| ------------- | --------------------------- |
| 陀螺仪零偏校准       | 在小车静止时完成，上电后静止 2~3 秒        |
| 直线行驶纠偏        | 不是重新校准陀螺仪，而是“保持进入直线段时的 yaw” |
| `ZERO`/yaw 归零 | 在出发前做，不在直线运动中频繁归零           |
| 直线段目标 yaw     | 每进入一个新的前进/后退段时记录一次当前 yaw    |
**推荐实施步骤**

|阶段|做什么|目的|
|---|---|---|
|1|保持 `FIXED_ROUTE_STANDALONE_ENABLE = 1U`|保证现有固定路线能力不被破坏|
|2|单独启用 `MX_I2C1_Init()`、`IMU_App_Init()`、`IMU_App_Loop()`|只接入陀螺仪，不拉起激光和树莓派逻辑|
|3|上电后等待 IMU 校准完成，或超时后继续开环|防止因为 IMU 不可用导致小车不跑|
|4|固定路线启动时允许直线纠偏|只改变直线段表现|
|5|`StraightControl_Apply()` 中根据 yaw 偏差输出小 `wz`|用麦轮差速修正方向|
|6|IMU 异常时自动关闭纠偏|保留原来的开环直行能力|
|7|实车逐步调小/调大 PID 参数|避免蛇形摆动或修正不足|

**建议参数初值**

|参数|建议初值|说明|
|---|---|---|
|yaw 纠偏最大 `wz`|`0.15 rad/s`|先小一点，避免摆动|
|yaw 死区|`1.0~2.0 deg`|小误差不修正|
|yaw 比例系数 `Kp`|`0.8~1.2`|先只用 P 或极小 PI|
|积分 `Ki`|`0~0.03`|初期可先不用|
|微分 `Kd`|`0~0.02`|抑制摆动，谨慎加|
|IMU 启动等待|`2000~3000 ms`|给静止校准留时间|
|IMU 失效超时|`200~500 ms`|超时直接开环|

**安全回退逻辑**

|场景|处理|
|---|---|
|IMU 没初始化成功|路线继续按原开环直行|
|`imu_valid = 0`|不叠加 `wz`|
|`imu_calibrated = 0`|不叠加 `wz`|
|yaw 突跳过大|本段放弃纠偏|
|修正量超过限制|clamp 到最大 `wz`|
|小车进入横移/旋转段|自动重置直线纠偏状态|

我建议最终做成两个开关：  
`IMU_ASSIST_ENABLE` 控制是否单独启用 IMU；  
`ROUTE_STRAIGHT_YAW_ASSIST_ENABLE` 控制固定路线直线段是否使用 yaw 纠偏。
