# 上车联调模式说明

## 模块位置

| 项目 | 路径 | 说明 |
|---|---|---|
| 头文件 | `UserModules/bringup_mode/bringup_mode.h` | 对外调用入口、配置项和报告结构 |
| 源文件 | `UserModules/bringup_mode/bringup_mode.c` | 地址检查、单轮点动、方向校验、激光急停验证 |
| 示例入口 | `Templates/main_integrated_example.c` | 通过 `APP_ENABLE_BRINGUP_MODE` 临时启用 |

## 推荐调用入口

| 场景 | 建议调用 | 说明 |
|---|---|---|
| 首次上车整套流程 | `BringupMode_Init(&huart2); BringupMode_RunAll(0, 0);` | 放在 `Board_App_Init()`、`Mecanum_Init(&huart3)` 之后，`RemoteCmd_Init()` 之前 |
| 只检查 RS485 地址 | `BringupMode_RunAddressCheck(&report);` | 对 `0x01` 到 `0x04` 的预期地址逐个读速度反馈 |
| 只做单轮点动 | `BringupMode_RunMotorJogSelfTest(&cfg, &report);` | 顺序为 FL、FR、RL、RR，每次只给一个轮正向小转速 |
| 只做方向校验 | `BringupMode_RunWheelDirectionCheck(&cfg, &report);` | 依次执行前进、左移、原地旋转，并输出四轮期望转速符号 |
| 只验激光急停 | `BringupMode_RunLaserEstopVerify(&cfg, &report);` | 慢速前进，挡板进入过近阈值后立即触发外部急停和电机急停 |
| 清除激光急停 | `BringupMode_ClearLaserEmergency();` | 移开障碍物且激光恢复安全距离后再调用 |

`Templates/main_integrated_example.c` 默认：

```c
#define APP_ENABLE_BRINGUP_MODE     0U
```

临时联调时改为 `1U`，并把 `UserModules/bringup_mode` 加入 Include Path，同时把 `bringup_mode.c` 加入编译。

## 默认参数

| 参数 | 默认值 | 作用 |
|---|---:|---|
| `jog_rpm` | 35 rpm | 单轮点动转速，按轮序经过 `MotorManager_SetSingleWheelRpm()` |
| `jog_hold_ms` | 700 ms | 单轮保持时间 |
| `direction_speed_mps` | 0.08 m/s | 前进、左移校验速度 |
| `rotate_radps` | 0.25 rad/s | 原地旋转校验角速度 |
| `laser_creep_speed_mps` | 0.05 m/s | 激光急停验证的低速前进速度 |
| `laser_verify_timeout_ms` | 10000 ms | 等待过近触发的最长时间 |
| `require_laser_safe_for_motion` | 1 | 方向校验前要求激光在线且未过近；架空车轮纯台架测试时可临时置 0 |

## 串口输出说明

| 前缀 | 示例 | 含义 |
|---|---|---|
| `BRINGUP ADDR` | `BRINGUP ADDR motor=FL addr=0x01 ret=OK rpm_milli=0` | 地址响应结果，`rpm_milli` 为 rpm * 1000 |
| `BRINGUP JOG_START` | `BRINGUP JOG_START motor=FR addr=0x02` | 开始点动指定轮 |
| `BRINGUP JOG_FB` | `BRINGUP JOG_FB motor=FR ret=OK rpm_milli=35000` | 点动期间读取到的速度反馈 |
| `BRINGUP DIR_EXPECT` | `BRINGUP DIR_EXPECT LEFT fl=-20372 fr=20372 rl=20372 rr=-20372 rpm_milli` | 当前动作下四轮期望符号，用于对照实车方向 |
| `BRINGUP LASER_ESTOP` | `BRINGUP LASER_ESTOP cause=TOO_CLOSE ... state=ESTOP ok=1` | 激光过近后已触发急停，`ok=1` 表示底盘进入急停态且目标速度清零 |
| `BRINGUP REPORT` | `BRINGUP REPORT overall=OK addr_mask=0x0F jog_mask=0x0F` | 汇总结果，`0x0F` 表示四个轮位都通过对应步骤 |

## 现场调试顺序

| 步骤  | 操作                                            | 判定                                                               |
| --- | --------------------------------------------- | ---------------------------------------------------------------- |
| 1   | 架空车轮，确认急停开关、电源限流和串口日志可用                       | 电机可空载转动，人员远离车轮                                                   |
| 2   | 运行 `BringupMode_RunAddressCheck()`            | `addr_mask=0x0F`；若缺位，先检查地址、A/B 线、波特率和供电                          |
| 3   | 运行 `BringupMode_RunMotorJogSelfTest()`        | 只有日志指示的一个轮转动；若轮位不对应，调整电机地址                                       |
| 4   | 运行 `BringupMode_RunWheelDirectionCheck()`     | 前进、左移、旋转方向符合预期；若单轮反向，使用 `MotorManager_SetDirectionSigns()` 标定    |
| 5   | 放下小车，低速运行 `BringupMode_RunLaserEstopVerify()` | 挡板进入 `MS53L1M_STOP_DISTANCE_MM` 附近后输出 `cause=TOO_CLOSE` 且 `ok=1` |
| 6   | 移开挡板后调用 `BringupMode_ClearLaserEmergency()`   | 串口输出 `BRINGUP CLR ret=OK`，底盘可重新进入正常控制                            |

## 注意事项

| 项目 | 建议 |
|---|---|
| 车轮安全 | 单轮点动和方向校验都建议先架空车轮；放地前把速度参数保持在默认小值 |
| 激光安全 | 激光无效或过近会被视为不安全；`ClearLaserEmergency()` 只有在激光在线且距离安全时才会解锁 |
| 方向标定 | `DIR_EXPECT` 给的是控制期望符号，实车方向仍需人工观察；最终通过 `MotorManager_SetDirectionSigns()` 或配置修正 |
| 正常固件 | 联调完成后把 `APP_ENABLE_BRINGUP_MODE` 改回 `0U`，保留模块源码也不会影响正常主循环 |
