# 1. 基础要求
该工程秉持 **能简则简** 的基本原则，要求简化一切不必要功能，只保留最基础的按预定路径运行的功能。优先保证代码的可运行性。
# 2. 需要实现的功能
通过写死具体路径，实现最基础的功能： **按给定路径写死，拿到基础分数**  
路径如下：直行3700mm，逆时针旋转90°等待3s，直行1500mm等待70s；逆时针旋转90°直行900mm再向右平移260mm，直行2100mm等待70s；在向左平移300mm再直行400mm再向右平移300mm
小车行驶时，使用陀螺仪进行位置辅助校准

其中每次停止点需要留够70秒，此时小车机械臂夹取小球（该功能不是这块stm32开发板负责）

# 3. 具体硬件调用
只需要使用以下硬件，足以完成考试时任务
## 1. 主控：stm32C8T6
## 2. JY61P 陀螺仪
作用：仅需要获取小车偏航角和大致位置，用于校准小车轨迹
陀螺仪通过i2c1挂在stm32开发板的**PB6、PB7**引脚下

根据陀螺仪安装位置，车体坐标系固定如下：

| 坐标轴 | 正方向 | 含义 |
|---|---|---|
| X 轴 | 小车左侧 | 横移方向 |
| Y 轴 | 小车正前方 | 前后运动方向 |
| Z 轴 | 小车正上方 | 旋转轴方向 |

# 3. ZDT-X42-V2 张大头42步进电机（4个）
作用：作为小车底盘，控制连接在步进上的麦轮进行移动，具体硬件参数如下：
张大头电机使用uart1与stm32通信，使用**PA9、PA10**引脚
电机上都有RS485模块，通过RS485总线和开发板通信
四轮位置与电机地址

四个电机地址与小车位置关系固定如下：

```text
车头方向：+Y

左前轮  右前轮
0x01    0x02

左后轮  右后轮
0x03    0x04
```

| 轮子位置 | 电机地址 | 说明 |
|---|---:|---|
| 左前轮 | `0x01` | 固定映射，不允许后续模型擅自修改 |
| 右前轮 | `0x02` | 固定映射，不允许后续模型擅自修改 |
| 左后轮 | `0x03` | 固定映射，不允许后续模型擅自修改 |
| 右后轮 | `0x04` | 固定映射，不允许后续模型擅自修改 |

### 2. 麦轮安装纹路

麦克纳姆轮安装纹路已确认：

| 项目 | 约束 |
|---|---|
| 安装形态 | X 型交叉状 |
| 纹路关系 | 斜对角线方向上的麦轮纹路方向相同 |
| 后续要求 | 运动学符号必须基于该安装方式设计，并在测试流程中加入方向验证 |

若实际运动方向与理论方向不一致，后续代码生成时只能通过方向修正系数或电机方向配置调整，不得改变电机地址映射。

### 3.机械参数
| 参数           |                符号 |                 数值 |
| ------------ | ----------------: | -----------------: |
| 麦克纳姆轮直径      |               `D` |    75 mm = 0.075 m |
| 麦克纳姆轮半径      |       `r = D / 2` | 37.5 mm = 0.0375 m |
| 单轮厚度         |                 - |              33 mm |
| 左右轮中心间距 / 轮距 |               `W` |   320 mm = 0.320 m |
| 前后轮中心间距 / 轴距 |               `L` |   220 mm = 0.220 m |
| 麦轮旋转耦合臂长     | `K = (L + W) / 2` |            0.270 m |
| 轮周长          |          `C = πD` |          0.23562 m |
