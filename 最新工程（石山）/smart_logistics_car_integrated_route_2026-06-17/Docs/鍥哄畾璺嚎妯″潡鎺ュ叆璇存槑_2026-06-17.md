## 1. 接入点

本次新增模块位于：

```text

├── competition_route.h
└── competition_route.c
```

主程序修改文件：

```text

```

```text

```

## 2. 主循环调用顺序

`main.c` 的主循环调用顺序调整为：

```c
Board_App_Loop();          // 更新 IMU / 激光快照
CSV_Debug_Loop(&huart2);   // 保持原有 CSV 调试输出
RemoteCmd_Loop();          // 处理树莓派链路、心跳、激光急停
CompetitionRoute_Loop();   // 固定路线状态机
Mecanum_PeriodicTask();    // 底盘控制周期任务
HAL_Delay(10);
```

这样做的原因是：路径模块执行前先拿到最新传感器状态，并让现有 `RemoteCmd` 的心跳超时、激光急停、外部急停逻辑优先生效。

## 3. 最小实现方案

路径模块只做轻量状态机，不修改底层电机、IMU、激光、Modbus 驱动。

复用的现有接口：

| 接口 | 用途 |
|---|---|
| `Sensor_GetSnapshot()` | 获取 IMU yaw、激光距离、激光告警等级、传感器有效性 |
| `Mecanum_SetVelocity()` | 下发底盘速度，执行直行、横移、旋转 |
| `Mecanum_Stop()` / `Mecanum_EmergencyStop()` | 路径结束、异常中止 |
| `Mecanum_EnableStraightControl(1)` | 复用现有直线闭环控制，直行/后退时保持航向 |
| `RemoteCmd_GetStatus()` | 检查树莓派链路和心跳状态 |
| `ChassisControl_SetExternalEmergency()` | 异常中止时复用底盘外部急停锁定 |

## 4. 默认路线

默认路线写在 `competition_route.c` 的 `g_default_route[]` 中：

| 步骤 | 动作 |
|---|---|
| 1 | 向前 3300 mm |
| 2 | 逆时针原地旋转 90° |
| 3 | 向前 1000 mm |
| 4 | 逆时针原地旋转 90° |
| 5 | 向前 1000 mm |
| 6 | 后退 1000 mm，回到前一个位置 |
| 7 | 向前 500 mm |
| 8 | 向右平移 350 mm |
| 9 | 向前 1500 mm |
| 10 | 向左平移 400 mm |
| 11 | 向前 700 mm |
| 12 | 停车 |

## 5. 动作完成判据

| 动作 | 完成判据 |
|---|---|
| 直行/后退 | 按 `距离 / 速度` 计算运行时间，当前为轻量开环距离控制 |
| 横移 | 按 `距离 / 速度` 计算运行时间，当前为轻量开环距离控制 |
| 原地旋转 | 使用 `Sensor_GetSnapshot()` 的 IMU yaw，误差连续多次小于约 2° 后完成 |
| 停车等待 | 停车并等待指定毫秒数；本次默认路线未插入额外等待步 |
| 停车 | 停止并置为 `FINISHED` |

## 6. 安全中止条件

路径运行中满足任一条件会立即中止：

- 激光有效且告警等级达到 `3`，即现有激光急停级别。
- 路径已经开始后激光失效，默认按安全策略中止。
- 树莓派链路已经建立后发生心跳超时。
- 底盘进入 `FAULT` 或 `EMERGENCY_STOP`。
- 旋转动作期间 IMU 数据无效或未校准。
- 旋转超时。

中止后会调用：

```c
ChassisControl_SetExternalEmergency(1U);
Mecanum_EmergencyStop();
```

需要通过现有远程命令 `CLR` 清除急停锁后才能恢复。

## 7. 默认启动行为

`competition_route.h` 中默认：

```c
#define COMPETITION_ROUTE_AUTO_START        1U
#define COMPETITION_ROUTE_REQUIRE_RPI_LINK  1U
```

因此固件上电后会进入 `WAIT_READY`，但不会立即运动。只有满足以下条件才会开始执行：

1. 树莓派链路处于 `REMOTE_CMD_LINK_ALIVE`。
2. IMU 数据有效且已完成校准。
3. 激光数据有效。
4. 底盘不处于故障或急停状态。

若调试时希望不依赖树莓派心跳，可临时把 `COMPETITION_ROUTE_REQUIRE_RPI_LINK` 改为 `0U`，但正式上车建议保持为 `1U`。

## 8. 需要实车标定的参数

以下宏建议在实车上逐步调小速度、逐段验证后再提高：

```c
#define COMPETITION_ROUTE_FORWARD_SPEED_MPS       0.18f
#define COMPETITION_ROUTE_STRAFE_SPEED_MPS        0.14f
#define COMPETITION_ROUTE_ROTATE_MAX_WZ_RADPS     0.45f
#define COMPETITION_ROUTE_ROTATE_MIN_WZ_RADPS     0.16f
#define COMPETITION_ROUTE_ROTATE_KP               1.25f
#define COMPETITION_ROUTE_ROTATE_TOL_RAD          0.035f
```

直行和横移当前仍是时间开环，不等价于精确里程闭环。建议第一次上车测试时把速度减半，并逐段确认 3300 mm、1000 mm、350 mm、400 mm 等距离的实际误差。
